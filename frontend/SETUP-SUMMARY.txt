🚀 TO START:

1. Get your Builder.io API key:
   → https://builder.io (sign up for free)
   → Account → Space Settings → Copy Public API Key

2. Add API key to .env file:
   REACT_APP_BUILDER_API_KEY=your_key_here

3. Make sure backend is running:
   cd ../backend
   npm start

4. Start the frontend:
   npm start

5. Visit:
   http://localhost:3000/demo (demo page)
   http://localhost:3000 (Builder.io page)
